Welcome to EcKit’s Documentation!
=================================

EcKit is a cross-platform C++ toolkit that supports the development of tools
and applications at ECMWF. It provides an abstraction layer on top of the
operating system, together with facilities for configuration, I/O,
serialisation, networking, logging and error handling.

.. admonition:: EcKit has a Rust interface
   :class: tip

   EcKit can be used from Rust through the ``eckit`` and ``eckit-sys`` crates,
   which call the C++ library directly. See :doc:`content/rust/index` for an
   overview, the design approach and usage.
